Stats

Open your own saves to see your profiles, records, medals and unlocks. The files are read by this page in your browser; nothing is uploaded or kept.

Open your saves

  • A save backup .zip from the local game (Saves → Download backup), or a zip of the Windows build's save folder.
  • Or the Windows build's save folder itself (usually %LOCALAPPDATA%\xboxrecomp, or the folder you set with RECOMP_SAVE_DIR). Only the small save files in it are read, never the large disk images next to them.
  • Or drop the files or folder on this box.

How the save files are read: the save format notes. Values we have not confirmed are marked unconfirmed; fields we cannot name yet are listed as unknown in each file's details.

Your saves are read in this browser tab and dropped when you leave the page. Nothing is uploaded.
