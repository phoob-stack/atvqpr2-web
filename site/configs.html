Configs

Every setting the browser build has. Changes are kept in this browser as you make them, and the game on this site (Home → Play) uses them directly. Take them to the PC launcher's game as a launch link or settings text, or export a file.

Controls

Saves and start

The game on this site keeps saves in this browser's private storage for this site; the PC launcher's game keeps its own, for 127.0.0.1:8460. Back them up from its Saves tab ("Download backup"); the zip opens on the Stats page here and in the Windows build's save folder.

Edit as text

The whole config as JSON. Edit it here or paste one from elsewhere; it is checked as you type and applied only when it is valid. A setting left out goes back to its default.

    To the local game

    Launch link. Opens the local game at 127.0.0.1:8460 and starts it with this config's display, movie, frame-rate and saves options. It works with the local game as it is today.

    Open the local game with these settings

      Everything else (volume, FPS counter, keys, gamepad buttons): copy the settings text and paste it into the local game page under Settings → Edit settings as text → Apply text.
