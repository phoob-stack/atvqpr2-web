About

What this is

ATV Quad Power Racing 2 came out for the original Xbox in 2003. This project runs it on a PC, natively on Windows and in Edge or Chrome, by static recompilation: the game's x86 program is translated to C ahead of time and compiled for the target, and a runtime stands in for the console's kernel, graphics chip, sound chip and USB controllers. Nothing is interpreted instruction by instruction.

In the browser the C is compiled to WebAssembly. Each game thread gets its own worker, the console's GPU commands are recorded into frame packets and drawn with WebGPU (its vertex programs and pixel combiners become shaders), the sound runs through an AudioWorklet, and the game's files come from the browser's private storage.

The game is not included. No game content is part of this project: you must supply the files from your own legally owned USA retail disc. The recompiled code is produced on each player's own computer from their own disc and is never published. This site holds only our own code, text and settings.

Milestones

    Built with

    • xboxrecomp, an open-source static recompiler and Xbox runtime, which this project extends.
    • wasi-sdk for the WebAssembly build, and wgpu for the native WebGPU back end the shaders were first proven on.
    • The browser's own WebGPU, Web Workers, AudioWorklet, Gamepad API and private file storage.
    • Ideas from other browser ports of console games, notably the way their sites offer configs and stats. No code, text or art was taken from them.
