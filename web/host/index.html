About

What this is

ATV Quad Power Racing 2 (Climax, 2003) for the original Xbox, statically recompiled: the game's x86 code is translated to C ahead of time, built for WebAssembly, and run here with its graphics drawn by WebGPU and its sound played by an AudioWorklet. Nothing is emulated instruction by instruction.

No game data is included in this page or served by it. The server on this computer sends the page and the program only. The game's files come from your own copy, which you choose on the Play tab, and stay in this browser's private storage on this computer.

Using your own copy

  1. Copy the files of your ATV Quad Power Racing 2 disc to a folder: the one with default.xbe, ATV.bah, ATV.bad, Fonts, Movies, Music, Sound…
  2. On the Play tab, choose that folder. The page checks that default.xbe is the retail USA release (its size and SHA-256); other releases and modified copies are refused.
  3. The files are copied into the browser once (about 0.7 GB; "Skip the movies" saves about 380 MB). After that, Play starts straight away.

Game data → Forget game files removes the copy; your saves stay.

Credits

  • xboxrecomp: the static recompiler and the Xbox runtime under the game (kernel, NV2A, APU, USB).
  • nfsu2-web: the techniques this port learned from (frame packets drawn with WebGPU, a worker per guest thread, OPFS files, an AudioWorklet ring) and the idea of a start page like this one. No code, text or art is taken from it.
  • wasi-sdk: the WebAssembly compiler and C library.
  • wgpu (wgpu-native): the native WebGPU back end the shaders were proven on.
  • ATV Quad Power Racing 2 is the work of Climax and Acclaim. This is an unofficial project for people who own the game.
